# StudyFlow – Smart Study Planner 📚

StudyFlow is a personalized study planning application designed to help students manage their time, build consistent study habits, and prepare effectively for exams. It combines intelligent scheduling, task management, and productivity tools in one interactive platform.

## ✨ Features

- **User Authentication:** Secure login and signup functionality.
- **Personalized Study Planning:** Create study plans based on your exam date, daily study hours, and preferred study duration.
- **Smart Scheduling:** Organize study sessions with planned breaks and customized start times.
- **Study Timer:** Manage study sessions with a countdown timer.
- **Task Management:** Add study tasks and track completion progress with checklists.
- **Subject Management:** Organize learning activities by subject.
- **Calendar & Dashboard:** View your schedule and monitor your study activities.
- **Interactive Interface:** Enjoy a user-friendly design with engaging visual elements.
- **Progress & Gamification:** Encourage consistency and productivity through progress-tracking features.
- **Progressive Web App (PWA):** Includes features designed to support an app-like experience on compatible devices.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQL
- **Testing:** Python unit tests and JavaScript tests

## 🎯 Project Goal

The goal of StudyFlow is to make exam preparation more organized, manageable, and productive by helping students plan their time, balance focused study sessions with breaks, and track their daily progress.

## 🚀 Getting Started

1. Clone or download this repository.
2. Install the required Python dependencies using `requirements.txt`.
3. Configure the application and database as needed.
4. Run the application locally.
5. Open it in your browser and start planning your study sessions.
